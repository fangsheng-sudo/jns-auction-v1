## 1. 自查方式

对四批合约做了**审计式自查**：以「链上事实 / 规范文档 / 治理裁定」三类事实严格区分，
逐项核对代码行为与文档表述，并为每个结论标注依据（合约名 + 行号）。

## 2. 逐项结论（摘要）

| # | 问题 | 结论 | 依据 |
|---|---|---|---|
| Q1 | 拍卖中间态归属 | 归属**卖家本人**；第三方不可抢占；剩余风险为卖家自抢转（违约），代码接受该风险 | `设计说明.md`；`SecondaryMarket.sol` 校验 `ownerOf == 本合约` |
| Q2 | 退款方式 | **pull**（用户自取），非 push；恶意拒收**不阻塞**拍卖结束 | `EnglishAuction.sol`；`SecondaryMarket.sol` |
| Q3 | WJ 假设 | 非标准返回已兼容（无返回值放行）；**转账损耗/税费无防护**（无余额差校验）；`to == 0 或 WJ` 的赎回分支已拦截 | `contracts/deps/Deps.sol` |
| Q4 | 最小加价 | `ceil(最高价 × 5%)`，下限 1 WJ；griefing 有界（延时上限硬封顶） | `EnglishAuction.sol:136-143`；`SecondaryMarket.sol` |
| Q5 | 未启用路径 | 带 `onlyDeveloper` / `perUseFee = 0` ⇒ 外部无法误扣；已处理 | `NotificationService.sol` |
| Q6 | 紧急止损 | **无全局 pause**；分合约各有叫停出口；**缺口**：二级市场对已挂拍（有出价）无治理级中止 | `EnglishAuction.sol` / `JNSAuctionFactory.sol` / `ClaimRegistry.sol` / `NotificationService.sol` |

## 3. 补充追问（四项）

| # | 主题 | 结论 |
|---|---|---|
| 1 | 到期取回路径 | **双出口齐备**（permissionless `settle()` + 赢家超时退款）⇒ **无 NFT / 资金永久锁定** |

| 3 | 重入与不变量 | 重入**已处理**（CEI + `nonReentrant`，有专门测试）；**无** `invariant`/`fuzz` 覆盖（增强项），代码层面不变量成立 |
| 4 | 材料标注 | README「⚠️ 声明」段已标注硬前提；**建议不改代码** |

## 4. 残余风险（P2 级，均不阻塞）

| # | 说明 |
|---|---|
| P2-1 | 中间态抢转窗口（卖家自抢转，违约风险） |
| P2-2 | WJ 转账损耗/税费无防护（依赖标准 ERC20 硬前提） |
| P2-3 | 最小加价 5% 规则的依据待补（外部文档不可直连） |
| P2-4 | 全库无全局 `pause`；二级市场缺治理级中止（提请教审核方裁定） |
| P2-5 | 无 `invariant`/`fuzz` 覆盖（预留为后续增强） |
| P2-6 | `ClaimRegistry` 零调用点（是否接上待裁定） |

> 上述均为**已披露**项，不构成阻塞；修法待审查意见后统一处理。

## 5. 与安全底线相关的设计

- **零权限部署者**：owner 由 constructor 硬编码为多签 ⇒ 部署者仅承担 gas。
- **审核责任到人**：审核人白名单 + 会签，链上留痕；申请人不得自审。
- **`renounceOwnership` 全局禁用**：防止以弃权方式绕过治理。
- **紧急中止权主动披露**：`EnglishAuction` owner 可叫停**未结算**拍卖，中止后全额挂 pull 退款。
