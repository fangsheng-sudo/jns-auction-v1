# 部署说明（展开版）

> 本文是 [`../README.md`](../README.md) 部署相关内容的**展开版**，不替换 README 正文。
> 权威步骤以 [`../部署与多签执行清单.md`](../部署与多签执行清单.md) 为准；
> 本页只做导航与要点提炼。

## 1. 部署形态

- **链**：Jouleverse 主网 chainId **3666**（**无测试网**）
- **合约**：四批共 5 个（`JNSAuctionFactory` / `SecondaryMarket` / `ClaimRegistry` / `SubnameRegistry` / `NotificationService`），**全部不可升级**
- **EVM 版本**：`istanbul`（PUSH0 不可用）
- **RPC**：`$JNS_DAO_RPC_URL`（授权端点，部署时填入）

> 因无测试网且合约不可升级，**部署参数必须事前逐项核对、一次性正确**。

## 2. 脚本拆分（两部分）

| 脚本 | 作用 | 是否广播 |
|---|---|---|
| `script/Deploy.s.sol`（Part 1） | **仅部署** 5 个合约，不调用任何 setter | 是（`--broadcast`） |
| `script/SetterCalldata.s.sol`（Part 2） | **仅产出 calldata**，不部署、不发交易 | 否 |

**为什么必须拆开**：`owner-only` setter 若由部署者 EOA 调用，必然 `revert "Ownable: caller is not the owner"`。setter 必须由多签发起，脚本不代劳。

## 3. 权限设计要点

| 项 | 规定 |
|---|---|
| 部署广播者 | **普通 EOA**（部署**不需要** owner 权限） |
| constructor `owner` | **硬编码为 JNS DAO 多签**（不经 EOA 移交） |
| 多签地址可否广播 | **不可**（合约无私钥，无法签名） |
| 部署者权限 | **零权限** —— 仅承担 gas |

## 4. 部署后必调（仅 2 条，由多签 2/3 执行）

| # | target | 函数 | 说明 |
|---|---|---|---|
| 1 | `JNSAuctionFactory` | `setReviewer(审核人EOA, true)` | 审核人**不得填多签**，否则「审核责任到人」落空 |
| 2 | `ClaimRegistry` | `setRegistrar(factory, true)` | 使该场拍卖可登记待铸造任务 |

calldata 由 Part 2 脚本产出（`MultisigCall` 事件）。跨批手工项：**每次新建拍卖实例**后补 `registry.setRegistrar(auction, true)`。

## 5. 部署后核验清单

- [ ] 逐个调用 5 个合约的 `owner()`，**均等于 DAO 多签**
- [ ] 确认部署者地址**不持有任何 owner / 权限**
- [ ] 确认 `ClaimRegistry` 的 registrar 参数与工厂地址一致
- [ ] 确认既有 `JNS.owner()` 未被改动
- [ ] 现场字节码 hash 与审查基线**逐项一致**（见 [`依赖与可复现构建.md`](依赖与可复现构建.md)）
- [ ] 保留部署者余额变动与 gas 记录

## 6. 回滚

**合约不可升级 ⇒ 无回滚**。可用止损手段**仅限** Timelock / 多签层面（以 owner 身份调用既有 owner-only setter，或经 Timelock 决议执行）。
已知缺口：全库**无全局 `pause`**；`SecondaryMarket` 对**已挂拍且有出价**的拍品无治理级中止入口（详见 [`../风险清单.md`](../风险清单.md)）。
