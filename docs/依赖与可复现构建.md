# 依赖与可复现构建（展开版）

> 本文是 [`../README.md`](../README.md)「环境」章节的**展开版**，不替换 README 正文。
> 目的是回答一个不可升级合约的核心问题：**「部署的字节码，是否等于审查过的字节码？」**

## 1. 依赖来源：零外部依赖

| 项 | 结论 |
|---|---|
| Solidity 依赖 | **无** —— 合约与测试的全部 `import` 均指向**仓库内文件** |
| 包管理器 | **无** —— 无 `package.json` / `*.lock` / `lib/` / `.gitmodules` |
| 第三方库 | **无** —— 无 `forge-std`、无 `openzeppelin-contracts`、无 `solmate` |

**说明**：`contracts/deps/Deps.sol` 自带最小实现（`SafeERC20` / `ReentrancyGuard` / `Ownable` / ERC-721 相关接口），
其注释明确「与 OpenZeppelin 同名组件接口一致、行为等价」，自带是为让本批交付**自包含**。
测试侧使用自写的极简 `Vm` cheatcode 接口（`test/Smoke.t.sol`），**避免 forge-std 的网络依赖**。

⇒ 因**无外部依赖**，不存在「依赖版本漂移」这一攻击面。

## 2. 工具链锁定

| 项 | 值 | 是否锁定 |
|---|---|---|
| 编译器版本 | `solc = "0.8.0"`（`foundry.toml`） | ✅ **写死**（非 `^0.8.x`、非浮动） |
| 自动检测 | `auto_detect_solc = false` | ✅ **关闭** ⇒ 不会因环境不同而换编译器 |
| EVM 版本 | `evm_version = "istanbul"` | ✅ 写死 |
| 优化器 | `optimizer = true`，`optimizer_runs = 200` | ✅ 写死 |
| IR 路径 | `via_ir = false` | ✅ 写死 |
| fuzz | `runs = 256` | ✅ 写死 |

⇒ 编译器与优化参数**全部显式固定**，这是可复现构建的前提。

## 3. 可复现构建验证（2026-09-17）

**方法**：本地两次**独立干净重建**（清空 `out/` 后分别构建至两个输出目录），
逐合约比对 creation code 的 `sha256`（前 16 位）。

| 合约 | creation bytes | sha256（前 16 位） | 两次重建 |
|---|---|---|---|
| `JNSAuctionFactory` | 24,475 | `b7ef1dc68621472c` | 一致 ✅ |
| `SecondaryMarket` | 8,377 | `21873be56a53bced` | 一致 ✅ |
| `ClaimRegistry` | 7,158 | `217028c9ecad0a18` | 一致 ✅ |
| `SubnameRegistry` | 11,886 | `a26a937ceba1fd9d` | 一致 ✅ |
| `NotificationService` | 10,590 | `e4b97b3a2cc69186` | 一致 ✅ |

**结论**：
1. **同一环境下构建确定** —— 两次独立重建字节码**完全一致**（排除「产物不稳定」疑问）。
2. **与审查基线相符** —— 上述 5 个 hash 与本地基线表**逐项相同**（排除「基线漂移」疑问）。

**精度边界（如实标注）**：以上两次重建均在**同一机器、同一 solc** 下完成，
尚未跨环境比对（云端 runner 产物 vs 本地产物）。因编译器版本与参数已显式写死、且无外部依赖，
跨环境差异的理论来源仅剩 **foundry 版本**与**宿主机工具链**；部署当日建议在部署机复算并逐项比对（见 [`部署说明.md`](部署说明.md) §5）。

## 4. 动态拉取 / 远程执行入口

| 检查项 | 结果 |
|---|---|
| `ffi` 启用 | ❌ **未启用**（`foundry.toml` 无 `ffi = true`，默认 false） |
| 合约 / 脚本 / 测试内的网络调用（`curl` / `wget` / `http(s)://`） | ❌ **零命中** |
| 构建期脚本拉取远端依赖 | ❌ **无**（无 `remappings` 指向远端、无 submodule） |

⇒ **无任何动态拉取或远程执行入口**。

## 5. 结论分级

**已锁定**。

- 编译器与优化参数**显式写死**（`solc 0.8.0` + `auto_detect_solc = false`）
- 依赖**零外部引入**（无 lock 需求、无 submodule、无远程 remapping）
- **无** `ffi`、**无**网络调用、**无**远程执行入口
- 构建已验证**确定性**（两次独立重建一致）且与**审查基线相符**

**唯一待补**（非缺口，属部署日流程）：**跨环境一致性**未验证 —— 建议部署当日在部署机复算 hash 并逐项比对（该步骤已列入部署前置清单）。
