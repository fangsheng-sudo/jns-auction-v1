## 1. 四模块职责

| 模块 | 合约 | 职责 |
|---|---|---|
| ① 一级拍卖 | `EnglishAuction` + `JNSAuctionFactory` | 申请 → 链上审核（白名单会签） → 自动拍卖（168h） → 结算 → 多签铸造 |
| ② 二级市场 | `SecondaryMarket` | NFT 挂单 → 竞价 → 成交（手续费 1.5%） |
| ③ 子域名 | `SubnameRegistry` | ERC-721 子域名；纯数字 label；深度上限 5；1 WJ 铸造费 |
| ④ 提醒服务 | `NotificationService` | v1 不启用（`perUseFee = 0` 休眠），为将来预留 |

依赖层：`contracts/deps/Deps.sol` —— 自带最小实现（`SafeERC20` / `ReentrancyGuard` / `Ownable` / ERC-721 相关接口），**无外部库依赖**。

## 2. 一级拍卖流程

```
submitRequest(name, startingPrice, payloadHash)     申请人
        ↓  （请求登记，status = Pending）
approveRequest(requestId) × signersRequired         审核人（白名单，硬约束：申请人不得自审）
        ↓  （status = Approved）
createAuctionFromRequest(requestId)                 硬约束 require(status == Approved)
        ↓  （部署 EnglishAuction 实例，归属该请求）
bid(amountWJ)                                       任意用户；加价须 ≥ 最高价 + minIncrement()
        ↓  （末 10 分钟出价 → 延时 10 min；总时长上限 192h）
settle()                                            任意人可触发（permissionless）
        ↓
多签铸造（claim → unbind → transferFrom 转赢家）      JNS 硬约束 ⇒ 必然两笔交易
```

**超时出口**：`settle()` 为 permissionless；赢家可 `claimTimeoutRefund`；退款一律 **pull**（用户自取），恶意拒收不阻塞流程。

## 3. 二级市场流程

```
list(tokenId, startPrice, durationHours)            卖家；本 tx 内 NFT 转入托管
        ↓  （挂拍即托管）
bid(amountWJ)                                       任意用户
        ↓
settle()                                            任意人可触发
        ↓  （1.5% 手续费从成交额扣除 → 归 DAO 多签；卖家到手 98.5%）
```

**两笔交易约束**：受 JNS 硬约束（`unbind` 要求 `ownerOf == msg.sender`），托管与解绑**必然分两笔**；两笔之间存在「抢转窗口」，已在设计中披露（详见 `../设计说明.md`）。

## 4. 权限矩阵（摘要）

完整逐函数矩阵见 [`../设计说明.md`](../设计说明.md) §七。

| 合约 | owner（多签） | developer | 审核人 | 用户 |
|---|---|---|---|---|
| `JNSAuctionFactory` | `setReviewer` / `setSignersRequired` / `setAuctionBeneficiary` / 治理兜底 `releaseName` | — | `approveRequest` / `createAuctionFromRequest` / `cancelRequest` / `rejectRequest` | `submitRequest`（本人） |
| `EnglishAuction` | `emergencyCancel`（仅未结算） | — | — | `bid` / `withdrawRefund` / `settle`（任意） |
| `SecondaryMarket` | `setTradeFeeRate` / `setTradeFeeRecipient` | — | — | `list` / `bid` / `settle` / `cancelListing`（仅卖家、无出价） |
| `SubnameRegistry` | 费率与收款方 setter | — | — | `mintSubname` |
| `NotificationService` | 安全刹车类 setter | `setPerUseFee` / `setServiceFeeRecipient`（**独占**） | — | 订阅 |

**要点**：
- owner 恒为 **JNS DAO 多签**；部署者**不获得任何权限**。
- `developer` 变更权**仅其本人**（自转让；沉默 = 否决）。
- `renounceOwnership` **全局禁用**（防绕道弃权）。
- 无全局 `pause`；分合约各有叫停出口（详见 [`../风险清单.md`](../风险清单.md) X-10 与 §五）。

## 5. 状态机

- **请求（Factory）**：`Pending → Approved → AuctionCreated`；分支 `Cancelled` / `Rejected`。
- **拍卖（EnglishAuction）**：`Open → Ended → Settled`；分支 `Cancelled`（owner 紧急中止，仅未结算）。
- **挂单（SecondaryMarket）**：`Active → Ended → Settled`；分支 `Cancelled`（仅卖家、且无人出价）。
